## [1.0.0] — 2026-05-12

### Added
- Initial release of the Santos Populares 2026 dashboard
- Dynamic filters: date range, venue, artist, event type, context
- Summary metrics: total events, active venues, artists, peak day
- Calendar heatmap, daily pulse chart, venue and artist rankings
- Interactive agenda scatter plot
- Quick planning table (recommended venue per day)
- Artist presence tracker
- CSV export of filtered data
- Data loading pipeline with wide→long normalization from xlsx
- Pytest suite for data pipeline sanity checks
- GitHub Actions CI (Python 3.11 & 3.12)
- Streamlit Community Cloud ready
